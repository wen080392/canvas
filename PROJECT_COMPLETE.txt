🎨 FEATURE SHOWCASE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. SECRET SCANNING
   Input:  Terraform code with hardcoded secrets
   Output: Categorized findings (CRITICAL, HIGH, MEDIUM)
   
   Detects:
   • AWS Access Keys (AKIA*)
   • GitHub Tokens (ghp_*)
   • Private Keys (RSA, SSH)
   • Slack Webhooks
   • High-entropy strings (random API keys)

2. INFRASTRUCTURE VISUALIZATION
   Input:  Terraform HCL code
   Output: Interactive graph (nodes + edges)
   
   Shows:
   • Resource relationships
   • Architectural layers
   • Dependency chains
   • Network topology

3. AUTO-REMEDIATION
   Input:  Detected vulnerability
   Output: Fixed Terraform code + GitHub PR
   
   Fixes:
   • S3 bucket encryption
   • Security group restrictions
   • IAM role policies
   • RDS encryption
   • (Extensible via Strategy pattern)

4. COMPLIANCE REPORTING
   Input:  Infrastructure scan
   Output: Multi-framework compliance report
   
   Frameworks:
   • SOC2 (45 controls)
   • ISO27001 (114 controls)
   • HIPAA (32 controls)
   • GDPR (25 controls)
   • PCI-DSS (38 controls)

5. DRIFT DETECTION
   Input:  Terraform state + AWS API
   Output: Configuration drift alerts
   
   Detects:
   • Manual changes in AWS console
   • Deleted resources
   • Modified configurations
   • Security group changes
